# Zara's Little Universe

The installable (home-screen) version of the Zara's Little Universe claude.ai artifact.

- `index.html` is generated: `python3 build.py path/to/artifact.html`, then bump `VERSION` in `sw.js`.
- Everything a person makes is saved in their own browser (IndexedDB). Nothing is uploaded.
- Claude book picks only work in the claude.ai version; here the Library shows the hand-picked list.
- Photo stickers are not included in this public copy.
